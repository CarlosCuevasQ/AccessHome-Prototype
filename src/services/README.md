# Servicios

Los servicios de dominio se añadirán aquí cuando se implemente cada módulo. Las pantallas y hooks consumirán sus métodos asíncronos tipados; el acceso a localStorage quedará encapsulado en esta carpeta.

La futura integración con una API Django sustituirá la implementación de los servicios conservando el contrato usado por las pantallas. En la etapa 1 no hay datos de dominio, sesión ni persistencia que implementar.
